# FastAPI 도서 관리 API

## 프로젝트 소개
FastAPI와 HTML, JavaScript(Fetch API)를 이용한 도서 관리 프로젝트입니다.

## 구현 기능
- 상태 확인(Status)
- 도서 목록 조회
- 도서 단건 조회
- 도서 검색

## 사용 기술
- Python
- FastAPI
- HTML
- JavaScript (Fetch API)

## 실행 방법

```bash
fastapi dev main.py
```

브라우저에서 접속

```
http://127.0.0.1:8000/static/01-status.html
http://127.0.0.1:8000/static/02-list.html
http://127.0.0.1:8000/static/03-detail.html
http://127.0.0.1:8000/static/04-search.html
```
